# Демонстрационный проект

Демо-симулятор системы маршрутизации заявок на базе ИИ для сервисного центра.  

Генерирует синтетические клиентские заявки для вымышленного центра ремонта электроники и проводит их через реалистичный распределённый конвейер — брокер сообщений, RAG-классификатор, воркеры, и т. д.  

Интерфейс показывает трассировку заявок и нагрузку, потребление токенов и денег; позволяет инициировать сбои.  

Симулятор воспроизводит эксплуатационные практики промышленного уровня (метрики, логирование, ретраи, идемпотентность и т.д.) в контролируемой тестовой среде.
