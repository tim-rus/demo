# Демонстрационный проект

Демо-симулятор системы маршрутизации заявок на базе ИИ для сервисного центра. Генерирует синтетические клиентские заявки для вымышленного центра ремонта электроники и проводит их через реалистичный распределённый конвейер — брокер сообщений, RAG-классификатор, воркеры. Интерфейс показывает трассировку заявок и нагрузку, позволяет инициировать сбои, отслеживать потребление токенов и денег. Симулятор воспроизводит эксплуатационные практики промышленного уровня — метрики, логирование, ретраи и идемпотентность — в контролируемой тестовой среде.
